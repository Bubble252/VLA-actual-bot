---

## 1. 交付物

| 路径 | 说明 |
|------|------|
| `RTC/rtc_arx/chunk_queue.py` | 物理 ΔEEF chunk 队列（scale 前） |
| `RTC/rtc_arx/client.py` | `RTCDeltaEefClient`：`off` / `track_b` |
| `lewm_x5_grasp/scripts/eval_starvla_libero_x5.py` | 新增 `--rtc-mode` 等参数 |

---

## 2. 开关

| 模式 | 行为 |
|------|------|
| `--rtc-mode off`（默认） | 仍用 StarVLA `ModelClient`，与改前一致 |
| `--rtc-mode track_b` | 用 `RTCDeltaEefClient`：异步 prefetch，请求带 `rtc_*` |

环境变量等价：`RTC_MODE=track_b`、`RTC_EXECUTION_HORIZON=4`、`RTC_PREFETCH_REMAINING=4`。

---

## 3. track_b 行为摘要

```text
队列里还有 physical leftover
  → remaining <= prefetch_remaining 时后台推理
  → 请求：rtc_enabled + rtc_prefix(physical leftover) + inference_delay 估计
  → 返回后 skip=实际消耗步数，替换队列
夹爪：随 chunk 逐步下发；不单独进 guidance（server 维掩码）
pos_scale / rot_scale：仍只在积分下发时用，不进 leftover
```

---

## 4. 启动示例

```bash
# 默认：不开 RTC
bash lewm_x5_grasp/scripts/run_eval_starvla_libero_x5.sh ...

# 开 track_b（需 5694 已重启加载 P3）
POLICY_PORT=5694 RTC_MODE=track_b \
  bash lewm_x5_grasp/scripts/run_eval_starvla_libero_x5.sh --dry-run \
  -- --rtc-mode track_b --rtc-execution-horizon 4
```

或直接：

```bash
python3 lewm_x5_grasp/scripts/eval_starvla_libero_x5.py \
  --host 127.0.0.1 --port 5694 \
  --rtc-mode track_b --dry-run --max-steps 40
```

日志中 `rtc={mode,q,delay,srv}`：`srv=True` 表示 server 侧 `data.rtc.applied`。
