# 08 · P5 联调记录

> 日期：2026-08-08  
> 端口：**5694**（ΔEEF / `franka` / steps_98000）

---

## 1. 操作

1. 确认 P3 补丁在 `/root/code/Starvla`。  
2. 重启 `server_policy.py --port 5694`（`CUDA_VISIBLE_DEVICES=0`，`--use_bf16`）。  
3. 远端 websocket 烟雾：无 RTC / 有 RTC / 空 prefix。

---

## 2. 发现问题与修复

| 现象 | 原因 | 修复 |
|------|------|------|
| `rtc.applied=False`, `fell_back=True`, `infer: tensors does not require grad` | `QwenGR00T.predict_action` 的 `@torch.inference_mode()` 禁止 RTC autograd | RTC 打开时改用 `nullcontext()`，关闭时仍用 `inference_mode()` |

修复后已再次重启 5694。

---

## 3. 烟雾结果（远端 127.0.0.1:5694）

| 用例 | 结果 |
|------|------|
| 无 `rtc_*` | `applied=False`, `fell_back=False`, shape `(1,8,7)` |
| `rtc_enabled=True` + physical leftover `(5,7)` | **`applied=True`**, `fell_back=False`, 输出有限 |
| `rtc_enabled=True` + 空 prefix | `fell_back=True`, `empty_prefix`（预期降级） |

未在本机跑 D405/真机；client `--rtc-mode track_b` 路径已在 P4 交付，真机按需自行加 `--dry-run` 验证。

---

## 4. 结论

- Server 轨 B guidance **可用**（需异步 leftover + `rtc_enabled`）。  
- 默认不传 RTC 字段时行为安全。  
- 生产默认保持 `--rtc-mode off`；要用 RTC 时开 `track_b` 并确认 `applied=True`。
