## 1. 一次性依赖

```bash
cd ~/project/ARX_X5_clean_server46\(7.12get-data\)/lewm_x5_grasp/scripts/tool
pip3 install -r requirements.txt
```

默认自动找 URDF（优先 vendor `X5A.urdf`）。也可：

```bash
export X5_URDF_PATH=/path/to/x5.urdf
# 或
bash run_viz.sh --demo --urdf /path/to/X5A.urdf
```

若 MuJoCo 窗口打不开（Wayland）：

```bash
export MUJOCO_GL=glfw
# 或 EGL 无窗调试：
# export MUJOCO_GL=egl
```

### 2.1 HDF5 采集参考（P4）

EP=../../data/pour_foam_from_cup/episode_2026-07-14_201032.hdf5
bash run_viz.sh --demo --hdf5 "$EP" --ref-frame 10
# 只看采集图 / 鬼臂（总线空）：

## 3. 真机 + 策略 + UI（推荐终端布局）

共 **4～5** 个终端。路径默认 `7.12eval`。

### T1 · CAN

```bash
cd ~/project/ARX_X5_clean\(7.12eval\)
bash ARX_CAN/arx_can/arx_can1.sh
```

### T2 · ROS2 单臂

```bash
cd ~/project/ARX_X5_clean\(7.12eval\)
source /opt/ros/humble/setup.bash
cd ROS2/X5_ws && source install/setup.bash
ros2 launch arx_x5_controller open_single_arm.launch.py
```

确认：`ros2 topic hz /arm_status` 约 100Hz。

### T3 · Policy 隧道（按模型端口）

| MODEL | 典型端口 |
|-------|----------|
| `3p` / `3p_old` | 5794 |
| `1p` | 5694 |
| `2p` | 5695 |

```bash
cd ~/project/ARX_X5_clean\(7.12eval\)
# 若远端未起服务，先：
# FORCE_RESTART=1 MODEL=3p_old CKPT_STEP=10000 bash lewm_x5_grasp/scripts/deploy_20260718/start_remote_policy.sh
PORT=5794 bash lewm_x5_grasp/scripts/deploy_20260718/open_tunnel.sh
```

### T4 · Play UI（先开窗，等总线）

```bash
cd ~/project/ARX_X5_clean_server46\(7.12get-data\)/lewm_x5_grasp/scripts/tool
bash run_viz.sh --bus
# 可选：叠加某条采集参考轴
# bash run_viz.sh --bus --hdf5 /path/to/episode.hdf5 --ref-frame 0
# 可选：有 end_pos 时画 SDK 轴
# bash run_viz.sh --bus --show-sdk
```

默认场景带 **棋盘地板 + 天空渐变 + 多光源**（比纯黑背景清晰）。若要关地板：`--no-floor`。

### T5 · 策略 client（打开 play-viz 旁路）

```bash
cd ~/project/ARX_X5_clean\(7.12eval\)
# 方式 A：命令行
MODEL=3p_old bash lewm_x5_grasp/scripts/deploy_20260718/run_local_client.sh \
  --play-viz \
  --task "pick and place the can" \
  --max-steps 30

# 方式 B：环境变量
# X5_PLAY_VIZ=1 MODEL=3p_old bash lewm_x5_grasp/scripts/deploy_20260718/run_local_client.sh ...
```

`run_local_client.sh` 会自动把本工具目录加入 `PYTHONPATH`。日志出现 `[play-viz] ON` 即表示在写总线。

> 仅看真机反馈、不跑策略时：`bash run_viz.sh --ros`（需已 launch 单臂）。

## 4. 推荐启动顺序（一览）

```text
1. CAN → 2. ROS2 → 3. 隧道 → 4. run_viz.sh --bus → 5. run_local_client
关停：先 Ctrl+C client，再关 viz / launch / CAN
```

## 5. 常用排障

| 现象 | 处理 |
|------|------|
| 找不到 URDF | `export X5_URDF_PATH=...` 或 `--urdf` |
| 窗口黑/崩 | `MUJOCO_GL=glfw`；Wayland 试 X11 会话 |
| `--bus` 不更新 | 确认 client 是否 `publish`；`ls -l /tmp/x5_play_viz/latest.npz` |
| 臂不动只 UI 动 | 正常：UI 是旁路；查 ROS `/arm_cmd` |
| SDK 轴与模型末端差大 | 预期；主显示以 `q_cmd` FK 为准，`--show-sdk` 仅参考 |
